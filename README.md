# 🃏 PokerBot — покерный клуб в Telegram

Безлимитный Холдем с друзьями: бот-консьерж (приглашения, уведомления, итоги)
+ Mini App со столом. Кэш-игра на условные фишки, расчёт долгов в конце сессии.

**Как запустить после перезагрузки ПК — краткая памятка: [ЗАПУСК.md](ЗАПУСК.md)**

Полный дизайн-документ и план фаз — в **[PLAN.md](PLAN.md)**.

**Все фазы плана M1–M5 реализованы** — клуб полностью рабочий 🎉

## Возможности

- Создание стола с настройками: стек, блайнды, ребай, цена фишки, места, таймер хода
- Приглашение друзей ссылкой (`t.me/<bot>?startapp=tbl_<код>`), шэр в любой чат
- Лобби в реальном времени (WebSocket): места, состав, вход/выход
- Роль хоста: старт игры, кик, передача роли; авто-передача при выходе хоста
- **Полные раздачи Холдема**: свои карты видны только тебе, борд, банк,
  панель действий (фолд/чек/колл/бет-рейз со слайдером и пресетами),
  таймер хода с авточеком/фолдом, олл-ины, сайд-поты, сплиты, вскрытие
- Уведомление ботом «твой ход», если апп закрыт
- **Кэш-механика сессии**: ребай по режиму настроек, поздний вход
  со стартовым стеком между раздачами, выход = кэшаут, история рук
  (`/api/tables/<код>/hands`), ledger с балансом «куплено = выведено»
- **Расчёт долгов (M5)**: итоги в фишках и деньгах, минимальные переводы
  «кто кому сколько», сводка ботом в личку, «Поделиться итогами»
- Приятные мелочи: анимации карт и банка, сияние победителя, хаптика,
  звуки (🔊/🔇, по умолчанию выкл)

## Быстрый старт (разработка)

### Бэкенд

```bash
python -m venv .venv
source .venv/Scripts/activate      # Git Bash на Windows
pip install -r requirements.txt
cp .env.example .env               # вписать BOT_TOKEN от @BotFather
```

### Mini App

```bash
cd web
npm install
npm run build                      # сборка в web/dist — её отдаёт FastAPI
```

### Запуск

```bash
python -m app.main
```

- API: <http://localhost:8000/api/health>
- Mini App (сборка): <http://localhost:8000>
- Дев-режим фронта с hot reload: `cd web && npm run dev` → <http://localhost:5173>
  (API проксируется на бэкенд автоматически)

### Проверка внутри Telegram

Проще всего — скрипт (поднимет SSH-туннель pinggy, впишет адрес в `.env`
и запустит сервер с ботом):

```bash
./scripts/dev_start.sh
```

Затем открой бота в Telegram → `/start` → кнопка «🎰 Открыть покер-клуб».
Бесплатный pinggy-туннель живёт 60 минут — перезапусти скрипт, чтобы
получить новый адрес (данные сохраняются).

Если `api.telegram.org` недоступен из сети напрямую, бот использует пиннинг
официального IP (`TELEGRAM_API_IP` в `.env`, по умолчанию `149.154.167.220`).
Альтернатива — настоящий HTTP/SOCKS-прокси: `PROXY_URL=socks5://host:port`
(приоритетнее пиннинга). MTProto-прокси из ссылок `t.me/proxy?…` ботам
не подходят — они только для клиентов Telegram.

Без `BOT_TOKEN` процесс стартует в режиме «только API» — удобно для работы над фронтом.

### Разработка лобби в браузере (без Telegram)

Добавь в `.env` строку `DEV_MODE=1` и перезапусти процесс. Затем открой
<http://localhost:8000> (или `npm run dev` → :5173) — появится дев-вход:
укажи любой числовой ID и имя. Разные ID = разные игроки, так что можно
открыть пару окон браузера и проверить лобби «на двоих».
**В проде `DEV_MODE` держи равным 0.**

База по умолчанию — файл `pokerbot.db` в корне (меняется через `DATABASE_URL`).
