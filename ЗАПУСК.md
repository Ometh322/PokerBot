# 🚀 Запуск бота после перезагрузки ПК

Памятка на каждый день. Все зависимости уже установлены — после рестарта
ничего переустанавливать не нужно.

## Быстрый старт (одна команда)

Открой **Git Bash** в папке проекта и выполни:

```bash
cd /e/Zcode/Projects/PokerBot
bash scripts/dev_start.sh
```

Скрипт сам сделает всё нужное:

1. поднимет **туннель** с вахтой (если туннель умрёт — сам создаст новый
   и переключит сервер, игра не потеряется);
2. запустит **сервер с ботом** (@CartishkiBot).

Дождись двух строк в выводе:

```
[ЧЧ:ММ:СС] туннель: https://XXXX.lhr.life        ← публичный адрес
... Run polling for bot @CartishkiBot ...        ← бот на связи
```

Окно можно **свернуть** (не закрывать!) — это вся работа бота.

## Первый вход игроков

1. Открой в Telegram **@CartishkiBot** → `/start` → кнопка
   «🎰 Открыть покер-клуб». Свежая кнопка всегда ведёт на живой адрес,
   а старые кнопки в чате бот **перевязывает автоматически** после ротации
   туннеля (на это нужен один свежий `/start` после запуска).
2. В левом верхнем углу окна Git Bash показан вывод туннеля; если нужно
   проверить живость: открой `https://XXXX.lhr.life/api/health` —
   должно быть `{"status":"ok"}`.

## Как остановить

В окне скрипта нажми **Ctrl+C** — остановятся и сервер, и туннель.
Данные (стеки, история, долги) сохраняются в `pokerbot.db` — после нового
запуска всё на месте. Активная раздача при остановке, разумеется,
прервётся: останавливай между раздачами.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Бот молчит, в логе `ClientConnectorError` / `TelegramNetworkError` | Бот ходит в Telegram через **HAPP** (`PROXY_URL=http://127.0.0.1:10809` в `.env`). Запусти/включи HAPP (его HTTP-прокси на порту **10809**), бот переподключится сам за ~5 с. |
| «no tunnel here :(» при открытии приложения | Ротация туннеля (секунды). Закрой и заново открой приложение той же кнопкой. Вахта пересоздаст туннель за ~20 с. |
| «BOT_TOKEN не задан» в логе | Нет файла `.env`. Восстанови из `.env.example`, впиши токен. |
| «[Errno 98]/10048 адрес занят» при старте | Порт 8000 занят другим процессом. Закрой старый Git Bash с сервером или смени `PORT` в `.env`. |
| Изменил код фронтенда — в приложении старое | Пересобери: `npm --prefix web run build` (сервер перезапускать не нужно). |
| Окно скрипта мертво после сна ПК | Туннели не переживают сон. Просто запусти `bash scripts/dev_start.sh` заново. |
| Ошибки `ModuleNotFoundError` | Сломано окружение: `python -m venv .venv && .venv/Scripts/python -m pip install -r requirements.txt`. |

## Раздельные окна (если хочется видеть логи отдельно)

```bash
# Окно 1 — туннель:
bash scripts/tunnel_keepalive.sh

# Окно 2 — сервер:
.venv/Scripts/python -m app.main
```

Вариант провайдера туннеля: `TUNNEL_PROVIDER=pinggy bash scripts/tunnel_keepalive.sh`
(у pinggy своя страница-предупреждение — по умолчанию используется
localhost.run без неё).

## Разовая настройка: стабильный адрес туннеля (решает обрывы в долгой игре)

Бесплатные анонимные туннели живут 5–10 минут; вахта их пересоздаёт, но адрес
каждый раз новый — открытые у игроков приложения остаются на мёртвом домене.
Лечится постоянным поддоменом (free-тариф localhost.run, нужен только браузер):

1. Ключ уже сгенерирован: `.tools/lhr_key`. Его публичная часть:
   ```
   ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIAU/zDcuikdPR53949hHmDBuiJdXGnrK/bACd2e9pRgx pokerbot-lhr
   ```
2. Зарегистрируйся на <https://localhost.run> (Sign in → GitHub/Google) и в
   разделе настроек SSH-ключей добавь ключ выше.
3. Запусти туннель со стабильным доменом:
   ```bash
   LHR_DOMAIN=kartishki.lhr.life bash scripts/tunnel_keepalive.sh
   ```
   (имя можно взять любое свободное — проверь в браузере, что оно не занято).
4. Один раз напиши боту свежий `/start` — все кнопки теперь навсегда ведут
   на один адрес. Ротации туннеля игроки перестанут замечать: клиент сам
   переподключается, игра на сервере не прерывается.

Если порт 80 занять не удалось (адрес кем-то занят) — возьми другой поддомен.
