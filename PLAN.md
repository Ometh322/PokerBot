# 🃏 PokerBot — покерный клуб в Telegram

**Дизайн-документ и план разработки**
Версия: 0.2 · Обновлён: 2026-10-02 · Фаза **M2 завершена**, следующая — **M3 — движок раздачи**

---

## 1. Что строим

Telegram-бот + Mini App для игры в **безлимитный Техасский Холдем (кэш)** с друзьями.
Бот — «консьерж»: приглашения, уведомления о ходе, итоги сессии. Вся игра происходит
в веб-столе Mini App внутри Telegram.

Зафиксированные решения:

| Вопрос | Решение |
|---|---|
| Где живёт игра | Mini App (веб-стол), бот — тонкий слой поверх |
| Формат игры | Кэш: статичные блайнды, ребаи, свободный вход/выход |
| Бэкенд | Python: aiogram (бот) + FastAPI (REST/WebSocket/статика) в одном процессе |
| Фронтенд | React + Vite + TypeScript, Telegram WebApp SDK |
| Хранение | SQLite; схема рассчитана на переезд на Postgres без изменений |
| Деньги | Фишки условные: никаких платежей внутри бота. Цена фишки нужна только для финального расчёта долгов между друзьями |

## 2. Роли: бот и Mini App

| Задача | Кто выполняет |
|---|---|
| Приглашение по ссылке | Бот (deep link) → открывает Mini App нужного стола |
| Создание стола, настройки | Mini App |
| Лобби, состав, старт игры | Mini App |
| Игровой стол, действия, таймеры | Mini App (WebSocket real-time) |
| Уведомление «твой ход» при закрытом аппе | Бот (личное сообщение + кнопка) |
| Начало игры / крупные события | Бот (сообщение в личку участникам) |
| Итоги сессии и расчёт долгов | Mini App (экран) + Бот (сводка в чат) |
| Оплата | Нет. Расчёты — вне бота, между друзьями |

## 3. Игровой цикл

1. **Создание стола.** Игрок открывает бота → кнопка «🎰 Открыть покер-клуб» →
   Mini App → «Создать стол» → форма настроек → стол получает короткий код и ссылку.
2. **Приглашение.** Ссылка `https://t.me/<bot>?startapp=tbl_<code>` шэрится в любой чат.
   Клик у друга → Mini App открывается сразу на лобби этого стола
   (параметр приходит в `initData.start_param`).
3. **Лобби.** Видны настройки и состав. Хост: старт, кик, передача роли. Сесть можно
   в любое свободное место.
4. **Игра.** Круг за кругом: кнопка дилера двигается, блайнды списываются автоматически,
   раздача → торги → вскрытие → перенос стеков. Ребай — кнопкой за столом между раздачами.
   Друзья могут **подсаживаться** в процессе (со стартовым стеком) и **выходить**
   (стек уходит в итоговый расчёт).
5. **Финиш.** Хост жмёт «Завершить игру» (или стол пустеет) → экран расчёта в Mini App
   + сводка от бота в личку участникам.

## 4. Правила игры (NLHE, кэш)

- Стол **2–9 мест**, старт раздачи — минимум 2 игрока со стеком.
- Кнопка дилера двигается по часовой стрелке после каждой раздачи, пропуская пустые места.
- Блайнды статичные: SB/BB из настроек. Хедз-ап (2 игрока): дилер постит SB
  и действует первым на префлопе; на постфлопе первым действует BB.
- Улицы: префлоп → флоп (3 карты) → терн → ривер. Торги на улице идут до выравнивания
  ставок и полного круга действий.
- **Минимальный рейз** — размером не меньше последнего полного повышения в раздаче;
  олл-ин меньше минимума не открывает торги заново.
- Чек — если в кругу нет ставок; колл — по недобору; бет/рейз — от минимума до стека.
- **Олл-ины и сайд-поты:** банк делится на уровни по размерам максимальных вкладов;
  каждый уровень разыгрывается среди тех, кто внёс соответствующую сумму и не сбросил.
- **Вскрытие:** при уравненном олл-ине карты открываются сразу, борд добирается
  автоматически. Выигрыш всухую — победитель вправе сбросить карты в мук (не показывать).
- **Сплиты:** при равных руках банк делится поровну; нечётная фишка — первому месту
  слева от кнопки среди выигравших.
- **Таймер хода:** по истечении — авто-чек (если нет ставки) или авто-фолд.
  Работает и при закрытом аппе / заблокированном боте — игра не встаёт.
- **Ребай:** по настройке (`выкл / при стеке 0 / в любой момент`), размер = стартовый
  стек, принимается между раздачами, фиксируется в ledger.
- **Вход в игру:** любое свободное место, стек = стартовый (buy-in в ledger).
  **Выход:** только вне активной раздачи; стек изымается (cashout в ledger).

## 5. Настройки стола

| Параметр | Дефолт | Варианты | Пределы |
|---|---|---|---|
| Стартовый стек | 1 000 | 500 / 1 000 / 2 000 / свой | 100…1 000 000 |
| Блайнды (SB/BB) | 5/10 | 1/2, 5/10, 10/20, свои | BB ≥ 2, кратно SB |
| Ребай | при стеке 0 | выкл / при 0 / в любой момент | размер = стартовый стек |
| Цена фишки | 1 ₽ | «просто так» (0) / 0,1 / 1 / 10 ₽ / своя | 0…10 000 |
| Мест за столом | 6 | 2–9 | 2…9 |
| Таймер хода | 60 с | 30 / 60 / 90 / без лимита | 10…300 с |
| Название стола | «Покер N» | свободный текст | ≤ 32 символов |

Настройки неизменяемы после старта игры (кроме названия).

## 6. Экраны Mini App

### 6.1 Домашний
Список «Мои столы» (активные + приглашения по ссылкам), кнопка **«Создать стол»**,
профиль (имя/аватар из Telegram). В M1 — каркас: профиль, start_param, заглушки.

### 6.2 Лобби
Настройки (кратко, иконками), места за столом (занято/свободно), состав игроков,
кнопка «Пригласить» (TG share), панель хоста (старт/кик/передача роли).

### 6.3 Стол — главный экран

```
              Антон 990            Мария 985
                  ●D
        ┌───────────────────────────────┐
        │  Олег 1240        БАНК: 30    │
        │         A♠  7♦  K♣             │
        └───────────────────────────────┘

              ТВОИ КАРТЫ:  Q♠  J♠

    [ФОЛД]  [ЧЕК]  [КОЛЛ 25]  [РЕЙЗ ────●── 150]
```

- Овальный стол зелёного сукна, места по кругу: аватар, имя, стек, бейджи D/SB/BB.
- Активный игрок — **ободок-таймер** вокруг аватара (progress ring).
- Борд и банк — в центре стола; карты с анимацией выдачи/переворота.
- Панель действий появляется только когда твой ход: Фолд / Чек / Колл (сумма
  указана) / Рейз со слайдером и пресетами `2,5x · банк · всё · своё`.
- Список допустимых действий и их пределы **считает сервер** (`legal_actions`),
  клиент только рендерит — нельзя отправить нелегальный ход.
- Твои карты приходят только в твой сокет и не покидают сервер иначе.
- Кнопка «Ребай» — между раздачами при стеке 0 (или всегда, по настройке).
- Хаптика: лёгкий отклик на действия, `success` на выигрыш раздачи.

### 6.4 Расчёт
Итоговая таблица сессии + свёртка долгов (см. §12) + кнопка «Поделиться итогами»
(бот пришлёт сводку в чат).

### 6.5 Стиль

| Элемент | Значение |
|---|---|
| Фон | `#0E1613`, мягкий зелёный градиент сверху |
| Панели | `#17231D`, граница `#24352C`, радиус 16px |
| Сукно стола | градиент `#1E5C40 → #16492F` |
| Акцент (кнопки, фишки) | золото `#F2B53B` |
| Текст | `#E9F1EC`, вторичный `#8FA79B` |
| Фолд/опасность | `#E26D5A` |
| Карты | белые плашки `#FAFAF7`; масти `#D0342C` / `#1B1B1B` |
| Цифры | `font-variant-numeric: tabular-nums` — стеки не «пляшут» |
| Шрифт | системный (-apple-system / Segoe UI / Roboto) |

Тёмная тема по умолчанию; учитываем `themeParams` Telegram. Ничего кричащего:
акустика игры — карты и фишки, а не интерфейс.

## 7. Архитектура

```
┌────────────── Telegram ──────────────┐
│  Чат с ботом          Mini App       │
│  • /start, ссылки     • лобби, стол  │
│  • «ход твоё»         • действия     │
└───────┬──────────────────┬───────────┘
        │ Bot API (polling)│ HTTPS / WSS (initData)
┌───────▼──────────────────▼───────────┐
│           Один процесс Python        │
│  ┌─────────┐      ┌───────────────┐  │
│  │ aiogram │      │    FastAPI    │  │
│  │  бот    │      │ REST + WS +   │  │
│  └─────────┘      │ статика web/  │  │
│                   └───────┬───────┘  │
│  ┌────────────────────▼───────────┐  │
│  │     Игровой движок (чистый)    │  │
│  │  колода, торги, сайд-поты,     │  │
│  │  оценка рук, таймеры           │  │
│  └───────────────┬────────────────┘  │
│  ┌───────────────▼────────────────┐  │
│  │ Состояние столов (в памяти) +  │  │
│  │ SQLite: игроки, ledger, руки   │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

Принципы:

- **Один процесс, один event loop**: `asyncio.gather(polling, uvicorn.serve())`.
  Для компании друзей этого достаточно; при необходимости масштабирования
  бота и API легко разнести по процессам — код разделён.
- **Движок изолирован**: чистый Python без Telegram/FastAPI-зависимостей,
  тестируется юнит-тестами напрямую.
- **Realtime**: WebSocket-комната на каждый стол (`/ws/table/{code}`); сервер
  рассылает снапшоты состояния после каждого события. Приватные данные
  (карты) отправляются только в сокет владельца.
- **Игрок офлайн ≠ пауза**: таймеры тикают на сервере; при наступлении хода
  бот шлёт личное сообщение с кнопкой открытия стола; таймаут — авточек/фолд.
- **Восстановление**: Mini App при открытии тянет полный снапшот, WS переподключается
  автоматически; состояние столов переживает рестарт процесса (персист в SQLite).

## 8. Модель данных

Реализованы в M2: `users`, `poker_tables`, `table_players`. Руки и ledger — в M3/M4.

| Таблица | Поля | Назначение |
|---|---|---|
| `users` | tg_id PK, first_name, last_name, username, photo_url, created_at, last_seen_at | профиль из Telegram (обновляется при каждом входе) |
| `poker_tables` | code PK (`tbl_7f3k` → код `7f3k`), name, host_user_id, status (lobby/active/finished), settings_json, created_at, finished_at | стол и его настройки |
| `table_players` | table_id, user_id, seat 0–8, status (waiting/playing/sitting_out/left), stack, total_bought, joined_at, left_at | участник стола; PK (table_id, user_id) |
| `hands` | id, table_id, number, dealer_seat, board_json, pot_total, result_json, created_at, finished_at | история раздач |
| `hand_players` | hand_id, user_id, seat, hole_cards_json, start_stack, end_stack, contributed, folded, showed | вклад участников в раздачу |
| `ledger_entries` | id, table_id, user_id, kind (buyin/rebuy/cashout), chips, money, created_at | деньги сессии — источник расчёта |

Инвариант ledger: `итог игрока = финальный стек − total_bought`; сумма итогов
всех игроков сессии = 0 (проверяется тестом).

### WebSocket `/ws/table/{code}?token=…` (M2 ✅, действия игры — в M3)

Клиент → сервер:

```jsonc
{ "type": "sit", "seat": 3 }
{ "type": "stand_up" }
{ "type": "start_game" }               // хост, нужно 2+ игроков
{ "type": "end_game" }                 // хост
{ "type": "kick", "user_id": 12 }      // хост, только в лобби
{ "type": "transfer_host", "user_id": 12 }
{ "type": "ping" }
// В M3 добавятся: { "type": "action", "action": "fold|check|call|bet|raise", "amount": 40 }
// В M4 добавится: { "type": "rebuy" }
```

Сервер → клиент:

```jsonc
{ "type": "state", "state": { ...снапшот... } }   // всем, после каждого события
{ "type": "your_cards", "cards": ["Qs", "Js"] }   // только владельцу
{ "type": "turn", "deadline": 1790000000 }        // только действующему
{ "type": "hand_result", "..." : "..." }          // итог раздачи всем
{ "type": "error", "message": "..." }
```

Форма снапшота (публичное + приватное сливается на сервере под каждого получателя):

```jsonc
{
  "table": { "code": "tbl_7f3k", "name": "Пятница", "status": "active", "settings": { } },
  "hand": {
    "number": 14,
    "board": ["As", "7d", "Kc"],
    "pot": 30,
    "dealer_seat": 1,
    "players": [
      { "user_id": 1, "name": "Антон", "seat": 1, "stack": 990,
        "bet": 0, "has_cards": true, "last_action": "check" }
    ],
    "to_act": { "user_id": 2, "deadline": 1790000000 }
  },
  "you": {
    "seat": 3, "stack": 990, "cards": ["Qs", "Js"],
    "legal_actions": { "fold": true, "check": true, "call": 0, "bet_range": [10, 990] }
  }
}
```

## 10. Безопасность и честность

- **Авторизация Mini App** — стандартная валидация `initData`: HMAC-SHA256
  с токеном бота, проверка свежести `auth_date` (≤ 24 ч). После входа сервер
  выдаёт собственный сессионный токен (HMAC, 30 дней) для REST и WS.
- **RNG** — перемешивание `secrets`-генератором на сервере; клиент никогда
  не получает чужих закрытых карт и не влияет на раздачу.
- **Легальность действий** проверяет только сервер (`legal_actions`);
  клиент — тонкий рендер.
- **История рук** сохраняется полностью — «а давай посмотрим, что у него было»
  решается открытием аппа, а не спором. Карты сброшенных в мук не показываются.
- Rate-limit на действия (защита от флуда кнопкой), size-limit на WS-сообщения.
- Цена фишки — расчётная величина, ботом не производится ни один платёж.

## 11. Покерный движок (M3)

Модули:

- `deck.py` — карта (ранг+масть), колода, перемешивание.
- `evaluator.py` — оценка лучших 5 из 7 карт (обёртка над `eval7`/`treys`).
- `betting.py` — круг торгов: чей ход, легальные действия, мин-рейз, ставки.
- `pots.py` — построение сайд-потов и распределение с учётом сплитов.
- `hand.py` — `HandRunner`: конечный автомат раздачи
  (preflop→flop→turn→river→showdown), вскрывает/мукает, добирает борд.
- `table.py` — стол: места, кнопка, блайнды, стеки между раздачами.

Инварианты (проверяются тестами после каждого действия):

1. Сумма стеков + ставок на столе + банка = сумме стеков на старте раздачи.
2. Каждый сайд-пот распределён полностью, остаток 0.
3. Игрок не может внести больше стека; превышение трактуется как олл-ин.
4. Ход всегда у ровно одного игрока (или у никого — улица закрыта).

Известно сложное (покрывается отдельными тестами): многоуровневые сайд-поты
при нескольких олл-инах; сплиты и нечётная фишка; хедз-ап-порядок торгов;
мин-рейз и «не открытие» торгов недоминимальным олл-ином; авточек/фолд
по таймеру; отключение игрока посреди раздачи.

Стратегия тестирования: юнит-тесты модулей + сценарные («сыграли раздачу,
проверили инварианты и результат») + генеративные (случайные раздачи со
случайными действиями — инварианты не нарушаются никогда).

## 12. Расчёт долгов в конце сессии

Ledger пишет каждое движение: buy-in, ребай, cashout.

```
итог_фишек(игрок) = финальный_стек − total_bought
итог_денег(игрок) = итог_фишек × цена_фишки
```

Сумма итогов по столу = 0. Долги сворачиваются до минимального числа переводов
жадным алгоритмом: на каждом шаге наибольший должник платит наибольшему
кредитору (итого ≤ n−1 переводов).

```
🏁 Сессия завершена — 27 раздач, 2 ч 40 мин
```

## 13. Запуск и деплой

### Разработка

```
python -m venv .venv && source .venv/Scripts/activate   # Windows Git Bash
pip install -r requirements.txt
cd web && npm install && npm run build                  # сборка Mini App → web/dist
cp .env.example .env        # вписать BOT_TOKEN от @BotFather
python -m app.main          # бот + API на :8000, Mini App на http://localhost:8000
```

Mini App требует публичный **HTTPS**: `cloudflared tunnel --url http://localhost:8000`,
полученный адрес вписать в `.env` как `BASE_URL` и перезапустить процесс. После этого
кнопка в боте открывает апп внутри Telegram.

### Прод

Минимальный VPS (1 vCPU / 1 GB): Caddy терминирует HTTPS и проксирует на порт
процесса; процесс под systemd; бэкап файла SQLite по крону. Альтернатива без
сервера — Railway/Render. Контейнеризация опциональна (один Dockerfile, статика
уже в образе после сборки).

### Переменные окружения

| Переменная | Обязательна | Значение |
|---|---|---|
| `BOT_TOKEN` | для бота | токен от @BotFather; без него режим «только API» |
| `BASE_URL` | да | публичный HTTPS-адрес Mini App/API |
| `HOST` / `PORT` | нет | слушающий адрес, дефолт `0.0.0.0:8000` |
| `DATABASE_URL` | нет | дефолт `sqlite+aiosqlite:///./pokerbot.db` |
| `DEV_MODE` | нет | `1` — разрешён дев-вход без Telegram (только для разработки) |
